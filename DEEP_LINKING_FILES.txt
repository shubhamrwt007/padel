ACTION REQUIRED - Complete These Steps:
---------------------------------------
1. GET APPLE TEAM ID
   - Visit: https://developer.apple.com/account
   - Click: Membership
   - Copy: Team ID (e.g., ABC123XYZ)
2. GET ANDROID SHA256 FINGERPRINTS
   - Run: ./get_sha256.sh
   - Copy both DEBUG and RELEASE fingerprints
3. UPDATE CONFIGURATION FILES
   - apple-app-site-association: Replace TEAM_ID
   - assetlinks.json: Replace YOUR_RELEASE_SHA256_FINGERPRINT
   - assetlinks.json: Replace YOUR_DEBUG_SHA256_FINGERPRINT
   - web_fallback.html: Replace YOUR_APP_ID in App Store URL
4. DEPLOY TO SERVER
   - Option A: Run ./deploy_deeplinks.sh (automated)
   - Option B: Manually upload files to swootapp.com
5. VERIFY IN XCODE
   - Open: ios/Runner.xcworkspace
   - Check: Signing & Capabilities → Associated Domains
6. INSTALL DEPENDENCIES
   - Run: flutter pub get
   - Run: cd ios && pod install && cd ..
7. TEST DEEP LINKS
   - Run: ./test_deeplinks.sh
   - Or manually test with provided commands
8. BUILD & DEPLOY
   - iOS: flutter build ios --release
   - Android: flutter build appbundle --release

✓ /tournament?tournamentId=XXX          → Tournament details
✓ /league?leagueId=XXX                  → League details

✓ /notifications                        → Notifications
✓ /leaderboard                          → Leaderboard
